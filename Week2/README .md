# Week 2: Data and Asset Classification

## Goal
Before deciding who can access data, decide how sensitive it is.

## What I did
1. Built a **four-level classification schema**: Public, Internal, Confidential, Restricted.
2. For each level, wrote who may access it and one handling rule (storage, transmission or disposal).
3. Classified **25 sample university records** (for example a course catalog, a transcript, payroll data, a database backup).
4. Wrote a short reason for every record that was hard to place.
5. Counted how many records fell into each level.

## Key ideas
- A level is defined by **how much harm disclosure would cause**, not by the type of document.
- Classification also considers integrity (would tampering matter?) and availability (would losing access hurt?).
- Labeling everything "Confidential" is a mistake: it slows work and people stop paying attention to labels.
- Borderline records are judgment calls, so writing the reason matters.
